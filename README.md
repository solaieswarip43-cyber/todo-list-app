# JavaScript Logic & State Management - To-Do List Application

An interactive, client-side To-Do List web application built to demonstrate DOM manipulation, event handling, and local data persistence.

## Features
- **Full CRUD Functionality**: Create, Read, Update, and Delete tasks seamlessly.
- **Local Data Persistence**: Saves tasks automatically using `window.localStorage` so data remains saved across browser reloads.
- **Advanced Filtering**: Filter tasks by status (`All`, `Active`, `Completed`).
- **Dynamic DOM & Event Delegation**: Optimized event handling using delegated event listeners.

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
